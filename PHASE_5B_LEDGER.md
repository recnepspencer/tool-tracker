## Boundary brief

- Batch 5A's TanStack Query boundary remains the only adapter-backed UI seam. `query-keys.ts` owns key vocabulary; tool and warehouse decision hooks own mutations; shared invalidation awaits every affected active and inactive projection.
- `MockDatabase` remains the sole command authority. Tool edits preserve custody and warehouse assignment; flags create condition evidence and audit events; restore is warehouse-held only; force return moves a worker-held unit to its assigned warehouse; decommission archives only warehouse-held units.
- Active administrators can manage all warehouse scopes; active warehouse managers can manage only their assigned warehouses. Unauthorized, inactive, pending, stale, and lifecycle-incompatible commands fail closed without partial writes.
- The flagged route derives from the existing `warehouseInventory` query family. It does not introduce a parallel flagged cache or direct adapter call.
